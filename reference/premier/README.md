# Premier Packout — where to put things

Source material for the Premier CX case study (`site/src/pages/work/_premier.astro`).
Nothing here is published directly; Claude pulls from it to fill the page.

- `current-site/` → **screenshots of the Premier page on jackmotzkin.com**, top to
  bottom. Full-page (scrolling) captures are ideal; if you take several, number them
  (`#1`, `#2`, …) so the order is clear. Claude takes the real copy from these.
- `journey-map/` → your **journey map** (the deliverable for the CEO), plus any
  drafts or earlier versions.
- `research/` → **research artifacts**: session notes, customer quotes, stakeholder
  maps, pain-point lists, or recommendation docs. Any format (image, PDF, doc) is fine.
- `photos/` → **images for the page**: a hero photo, Premier's logo, photos of the
  crews, trucks, or warehouse.

Not sure where something goes? Drop it in the closest folder, and Claude will sort it.
