# oxfam/process/ — wireframes, lo-fi, and process artifacts

The behind-the-scenes stuff that shows your thinking. Drop any of:
- Wireframes (low-fidelity)
- Lo-fi / paper prototypes, sketches
- Information architecture / sitemaps
- Iterations (v1 → v2 → …)
- Anything "before the polished screens"

Name them clearly if easy, e.g. `wireframe-landing.png`, `ia-sitemap.png`,
`lofi-v1.png`, `lofi-v2.png`. These feed the "Design decisions" and
"Design format & iteration" sections of the case study.
