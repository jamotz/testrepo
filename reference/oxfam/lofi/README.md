# oxfam/lofi/ — your low-fi MVP screenshots

Drop screenshots of your low-fidelity version of the wizard here (wireframes,
sketches, or a rough working MVP of the Contact-Us flow). This is what the
clickable prototype gets built from — name them by page/step if easy (e.g.
`landing.png`, `faq.png`), otherwise just tell Claude what's what.

This is separate from `process/`, which holds older process artifacts from
the case-study rebuild, and from `photos/`, which holds general imagery for
the build rather than screenshots of the flow itself.
