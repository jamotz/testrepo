# Origins — where to put things (app project)

- `flow/` → your **bubble graph** (pathways) and the **filter logic** (how filters
  query the database / avoid repetitive or wrong results). These are what Claude
  reads to build the interactive app prototype.
- `screens/` → full **screenshots** of each app screen (name them clearly, e.g.
  `home.png`, `product-detail.png`, `cart.png`).
- `assets/` → individual **images/icons** used inside the app screens.

We'll tackle Origins after Oxfam.
