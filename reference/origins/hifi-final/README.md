# Final hi-fi frames (Figma exports) — USE THESE

These are the FINISHED high-fidelity prototype frames, freshly exported from Figma.
This is the source of truth for recreating the hi-fi prototype and populating the
case study's results/redesign sections.

The sibling `../hifi/` folder holds the *midway* versions of the prototype — keep
them for the iteration story if useful, but prefer these final frames for anything
that represents the finished design.

## Export tips for cleanest results
- 2x PNG, one frame per file
- Name by screen: `home.png`, `shop.png`, `product-flower.png`,
  `filters-drawer.png`, `guide.png`, `cart.png`, `account.png`, etc.
- Include the filter states if you have them (empty result, applied) — they make
  the interactive rebuild much stronger.
